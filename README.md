### 🏆 Featured Project — FIFA World Cup 2026 Intelligence System

> A multi-agent AI system that reasons over real tournament data — not just a chatbot wrapper.

| Agent | Role |
|---|---|
| 🗂️ **Data Agent** | 11 tools for name-based (fuzzy-matched) lookups across matches, teams & players |
| 📊 **ML Agent** | Predicts real *and* hypothetical matchups from trained tournament features |
| 📚 **RAG Agent** | Answers rules/format/venue questions from an embedded knowledge base |
| 💡 **Insight Agent** | Plans → gathers → synthesizes genuine explanations, not just restated stats |
| ✅ **Action Agent** | Human-in-the-loop approval gate before any report is generated |
| 📝 **Report Agent** | Produces Markdown / JSON / CSV reports with AI-generated recommendations |

**Orchestrated with LangGraph** across five routes (data / ml / rag / insight / action), served through a **FastAPI** backend, with a **React + Vite + Tailwind** chat frontend polling live approval requests.
